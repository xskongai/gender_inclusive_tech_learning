# 函数解析：`to_5`

这个函数的作用是**把一个 0 到 1 之间的浮点数（比例值），转换成 1 到 5 之间的整数评分**（类似五星评分）。

## 逐步拆解

```python
def to_5(val: float) -> int:
    return max(1, min(5, round(val * 4 + 1)))
```

### 第一步：`val * 4 + 1` —— 线性映射

把 `[0, 1]` 区间映射到 `[1, 5]` 区间：

| 输入 `val` | `val * 4 + 1` |
|-----------|--------------|
| 0.0       | 1.0          |
| 0.25      | 2.0          |
| 0.5       | 3.0          |
| 0.75      | 4.0          |
| 1.0       | 5.0          |

这是一条直线变换：`y = 4x + 1`。

### 第二步：`round(...)` —— 四舍五入取整

把浮点结果变成最接近的整数。例如 `3.7 → 4`，`2.3 → 2`。

⚠️ 注意：Python 的 `round` 使用**银行家舍入法**（Bankers' rounding），即 `.5` 会向偶数靠拢，例如 `round(2.5) == 2`、`round(3.5) == 4`，这点和数学课本上的"四舍五入"略有不同。

### 第三步：`max(1, min(5, ...))` —— 边界钳制（clamp）

防止输入超出预期范围时结果越界：

- `min(5, x)` —— 上限不超过 5
- `max(1, ...)` —— 下限不低于 1

即使 `val` 是 `1.5` 或 `-0.3` 这种异常值，输出依然会被限制在 `[1, 5]` 内。

## 示例输出

```python
to_5(0.0)   # → 1
to_5(0.4)   # → 3   (0.4*4+1 = 2.6, round → 3)
to_5(0.8)   # → 4   (0.8*4+1 = 4.2, round → 4)
to_5(1.0)   # → 5
to_5(2.0)   # → 5   (被 clamp 限制)
to_5(-1.0)  # → 1   (被 clamp 限制)
```

## 典型使用场景

- 把模型输出的**置信度 / 概率**（0~1）转为五星评分显示
- 把**情感分析得分**、**相似度得分**等归一化数值转为可读的评级
- 把进度条百分比转换成五级图标

一句话总结：**归一化数值 → 五星评分的安全转换器**。
