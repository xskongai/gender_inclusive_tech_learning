# 区间重映射（Range Remapping）

## 一、问题的本质

区间重映射要解决的问题非常直白：

> 一个数 `x` 原本在区间 `[a, b]` 里，我想把它"按比例"挪到另一个区间 `[c, d]` 里去。

举个生活例子：
- 温度计上水银柱的高度是 `0~100mm`，对应温度 `0~100°C`
- 屏幕滑块位置是 `0~300px`，对应音量 `0~100`
- 模型输出的概率是 `0~1`，要显示成五星评分 `1~5`

这些都是同一个问题的不同外壳。

## 二、公式推导（两种思路）

### 思路一：先归一化，再放大

这是最直观的方式，**分两步走**：

**第一步：把 `x` 在 `[a, b]` 中的"相对位置"算出来（归一化到 `[0, 1]`）**

$$
t = \frac{x - a}{b - a}
$$

`t` 表示"`x` 走完了 `[a, b]` 的百分之多少"。例如 `x` 在正中央时，`t = 0.5`。

**第二步：把这个比例 `t` 应用到新区间 `[c, d]` 上**

$$
y = c + t \cdot (d - c)
$$

新区间的起点是 `c`，再往前走"`t` 那么大一段长度 `(d-c)`"就到目的地。

**合并起来：**

$$
\boxed{\;y = c + (x - a) \cdot \dfrac{d - c}{b - a}\;}
$$

### 思路二：两点确定一条直线

我们想要一条直线 `y = k·x + m`，满足两个端点对应：

- `x = a` 时 `y = c`
- `x = b` 时 `y = d`

**求斜率 `k`**（两点斜率公式）：

$$
k = \frac{d - c}{b - a}
$$

**求截距 `m`**：

$$
c = k \cdot a + m \;\Rightarrow\; m = c - k \cdot a
$$

最终：

$$
y = \frac{d-c}{b-a}(x - a) + c
$$

两种思路得到同一个公式 ✅

## 三、几何直觉

把它画在坐标系里就一目了然：

```
y
│
d ┤ - - - - - - - - - ●
│                  ╱
│              ╱
│          ╱
│      ╱
c ┤ ●
│  │              │
└──┼──────────────┼─────→ x
   a              b
```

- 这就是一条**穿过 `(a, c)` 和 `(b, d)` 的直线**
- 斜率 `(d-c)/(b-a)` 表示「输入每变化 1，输出变化多少」
- 输入区间 `[a,b]` 的长度被**拉伸或压缩**到输出区间 `[c,d]` 的长度

## 四、几个常见特例

### 1. 归一化（normalize）：映射到 `[0, 1]`

`c=0, d=1`：

$$
y = \frac{x - a}{b - a}
$$

机器学习里的 Min-Max Scaling 就是这个。

### 2. 反归一化（denormalize）：从 `[0,1]` 还原回 `[a,b]`

`a=0, b=1`：

$$
y = c + x \cdot (d - c)
$$

`to_n` 函数就是这个特例（`c=1, d=n`），所以才有 `val * (n-1) + 1`。

### 3. 对称区间互换：`[-1, 1] → [0, 255]`

常见于图像处理（把神经网络输出转成像素值）：

$$
y = (x + 1) \cdot 127.5
$$

### 4. 反转区间：`[0, 100] → [100, 0]`

注意 `c > d` 也完全合法，公式自动处理：

$$
y = 100 + (x - 0) \cdot \frac{0 - 100}{100 - 0} = 100 - x
$$

## 五、Python 通用实现

```python
def remap(x: float, a: float, b: float, c: float, d: float) -> float:
    """把 x 从 [a, b] 线性映射到 [c, d]"""
    return c + (x - a) * (d - c) / (b - a)
```

带钳制（防止 `x` 越界）：

```python
def remap_clamped(x: float, a: float, b: float, c: float, d: float) -> float:
    t = (x - a) / (b - a)
    t = max(0.0, min(1.0, t))   # 钳制到 [0,1]
    return c + t * (d - c)
```

使用示例：

```python
remap(50, 0, 100, 0, 1)        # → 0.5    （百分比归一化）
remap(0.8, 0, 1, 1, 5)         # → 4.2    （to_n 的原型）
remap(20, 0, 100, 100, 0)      # → 80     （反转）
remap(0.5, -1, 1, 0, 255)      # → 191.25 （图像像素）
```

## 六、常见陷阱

**1. `b == a` 会除零**  
源区间退化成一个点，无法定义映射。代码里要先判断。

**2. 越界输入的处理**  
公式本身不会限制输出范围——`x` 超出 `[a, b]` 时，`y` 也会超出 `[c, d]`，可能是想要的"外推"，也可能是 bug，看场景决定要不要 clamp。

**3. 取整时机**  
要整数输出时，应该「先映射后取整」，不要「先取整后映射」，否则精度损失严重。

**4. 非线性需求**  
这套公式只处理**线性**映射。如果原始数据分布不均（比如音频音量、亮度感知），可能要先取 log、再 remap，否则人眼/人耳感受不自然。

## 七、应用场景速览

| 场景 | 源区间 → 目标区间 |
|------|----------------|
| 进度条像素 | `[0, 1]` → `[0, screen_width]` |
| 评分系统 | `[0, 1]` → `[1, 5]` |
| 颜色归一化 | `[0, 255]` → `[0, 1]` |
| 摄氏华氏 | `[0, 100]°C` → `[32, 212]°F` |
| 游戏摇杆 | `[-32768, 32767]` → `[-1, 1]` |
| 音量曲线（线性段）| `[0, 100]` → `[-60, 0] dB` |
| 数据标准化 | `[min, max]` → `[0, 1]` |

一句话总结：**区间重映射 = 一条穿过两个端点的直线**，给定输入输出的「起点对起点、终点对终点」，剩下的就是按比例搬运。
