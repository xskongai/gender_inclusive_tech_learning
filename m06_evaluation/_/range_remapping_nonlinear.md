# 非线性区间映射

线性映射是「一条直线」，**非线性映射就是「一条曲线」**——同样穿过 `(a, c)` 和 `(b, d)` 两个端点，但中间的过渡不是匀速的，而是"先慢后快"、"先快后慢"、或者带有特殊形状。

## 一、通用框架

几乎所有非线性映射都可以套这个三步模板：

$$
\boxed{\;y = c + f(t) \cdot (d - c), \quad \text{其中 } t = \frac{x - a}{b - a}\;}
$$

- 先把 `x` 归一化到 `t ∈ [0, 1]`
- 用一个**形状函数 `f(t)`** 决定曲线长什么样，要求 `f(0)=0, f(1)=1`
- 再把结果按比例放回输出区间 `[c, d]`

线性映射只是 `f(t) = t` 的特例。换不同的 `f`，就得到不同的曲线。

## 二、常见的非线性映射公式

### 1. 幂函数（Power / Gamma）

$$
f(t) = t^{\gamma}
$$

最常用、最灵活的一种：

- `γ > 1`：**先慢后快**（凹形，开头压扁）
- `γ < 1`：**先快后慢**（凸形，开头陡峭）
- `γ = 1`：退化为线性
- `γ = 2`：平方曲线
- `γ = 0.5`：开方曲线

```
y
│           γ=0.5  ╭───
│              ╱──
│           ╱    γ=1
│         ╱   ╱
│       ╱  ╱
│     ╱ ╱
│   ╱╱    γ=2
│ ╱╱   ╱
│╱  ╱
└──────────────────→ t
0                  1
```

**应用**：图像 gamma 校正（屏幕亮度感知是 `γ≈2.2`）、动画缓动、音量曲线。

### 2. 对数映射（Logarithmic）

$$
f(t) = \frac{\log(1 + k \cdot t)}{\log(1 + k)}
$$

`k` 控制弯曲程度（越大越弯）。

特征：**开头变化剧烈，越往后越平缓**。

**应用**：
- 人耳对音量、人眼对亮度的感知都是对数的
- 分贝（dB）刻度
- 数据可视化中压缩大范围数值（地震震级、星等）

### 3. 指数映射（Exponential）

$$
f(t) = \frac{e^{k \cdot t} - 1}{e^{k} - 1}
$$

跟对数互为反函数。**开头平缓，越往后越陡**。

**应用**：人口增长、复利、放射衰变的反过程、动画里的"加速冲刺"。

### 4. Sigmoid / S 形曲线

$$
f(t) = \frac{1}{1 + e^{-k(t - 0.5)}}
$$

（实际使用时需要再做一次归一化，使 `f(0)=0, f(1)=1`，因为 sigmoid 在 0 和 1 处不会精确到 0 和 1。）

特征：**两头平、中间陡**，像 S 形。

```
y
│              ╭────────
│            ╱
│          ╱
│        ╱
│      ╱
│ ───╯
└──────────────────→ t
```

**应用**：
- 神经网络激活函数
- 平滑过渡动画（自然的"启动—加速—减速—停止"）
- 心理学/经济学里的「响应曲线」

### 5. Smoothstep（平滑阶跃）

$$
f(t) = 3t^2 - 2t^3
$$

或更平滑的 Smootherstep：

$$
f(t) = 6t^5 - 15t^4 + 10t^3
$$

特征：S 形，但**端点处导数为 0**（起步、停止都"无缝"）。

**应用**：图形学、Shader、游戏开发里的标准缓动函数。GLSL 直接有内建 `smoothstep()`。

### 6. 缓动函数（Easing Functions）

前端动画、游戏里的整套常用曲线，本质都是不同的 `f(t)`：

| 名称 | 公式 | 效果 |
|------|------|------|
| ease-in-quad | `t²` | 慢启动 |
| ease-out-quad | `1-(1-t)²` | 慢结束 |
| ease-in-out-quad | 分段 | 两端慢中间快 |
| ease-in-cubic | `t³` | 更陡的慢启动 |
| ease-in-sine | `1 - cos(πt/2)` | 三角函数缓动 |
| ease-out-bounce | 分段反弹 | 弹跳效果 |

完整列表参见 [easings.net](https://easings.net)（设计师常用速查表）。

### 7. 分段线性 / 折线映射

$$
f(t) = \text{在若干控制点之间分段做线性插值}
$$

最灵活、最"工程化"的方案：给一组 `(t_i, y_i)` 控制点，相邻两点之间走直线。

**应用**：色调映射 LUT、相机曲线、音频均衡器、游戏中的难度曲线。

### 8. 样条曲线（Spline）

贝塞尔（Bezier）、Catmull-Rom、B-spline 等。给几个控制点，得到一条光滑曲线。

CSS 里 `cubic-bezier(x1, y1, x2, y2)` 就是三次贝塞尔曲线。

## 三、Python 实现

```python
import math

def remap_nonlinear(x, a, b, c, d, mode="linear", k=2.0):
    """把 x 从 [a,b] 非线性映射到 [c,d]"""
    t = (x - a) / (b - a)
    t = max(0.0, min(1.0, t))   # 钳制,避免越界

    if mode == "linear":
        f = t
    elif mode == "power":
        f = t ** k
    elif mode == "log":
        f = math.log(1 + k * t) / math.log(1 + k)
    elif mode == "exp":
        f = (math.exp(k * t) - 1) / (math.exp(k) - 1)
    elif mode == "smoothstep":
        f = t * t * (3 - 2 * t)
    elif mode == "smootherstep":
        f = t * t * t * (t * (t * 6 - 15) + 10)
    elif mode == "ease_in_sine":
        f = 1 - math.cos(t * math.pi / 2)
    elif mode == "ease_out_sine":
        f = math.sin(t * math.pi / 2)
    else:
        raise ValueError(f"unknown mode: {mode}")

    return c + f * (d - c)
```

用法：

```python
remap_nonlinear(0.5, 0, 1, 0, 100, "linear")        # → 50
remap_nonlinear(0.5, 0, 1, 0, 100, "power", k=2)    # → 25  (先慢后快)
remap_nonlinear(0.5, 0, 1, 0, 100, "power", k=0.5)  # → 70.7(先快后慢)
remap_nonlinear(0.5, 0, 1, 0, 100, "smoothstep")    # → 50  (中点对称)
remap_nonlinear(0.5, 0, 1, 0, 100, "log", k=10)     # → 74.7(对数感知)
```

## 四、怎么选公式？

| 需求 | 推荐公式 |
|------|---------|
| 简单调节"快慢节奏" | 幂函数 `t^γ`（γ 一拨就行） |
| 模拟人耳/人眼感知 | 对数 |
| 模拟增长/衰变 | 指数 |
| 动画平滑过渡 | Smoothstep / 缓动函数 |
| 神经网络、概率压缩 | Sigmoid |
| 完全自定义形状 | 分段线性或贝塞尔 |

## 五、关键约束

不管选哪个 `f(t)`，**几乎所有正经映射都要求**：

1. **端点对齐**：`f(0)=0, f(1)=1`，保证映射后的范围正好是 `[c, d]`
2. **单调性**：`f(t)` 单调递增，保证大的输入对应大的输出（不发生"翻转")
3. **连续性**：曲线不能有跳跃断点

如果选了 sigmoid 这种"端点不严格归零"的函数，需要先做"归一化拉伸"，让它强行通过 `(0,0)` 和 `(1,1)`。

## 六、几何直觉总结

线性映射：

```
●────────────●
(a,c)        (b,d)
```

非线性映射：

```
●╮               ●─╮
 │╲              ╱  ╲
 │ ╲            ╱    ●          
 │  ╲          ╱     (b,d)
 │   ●        ●╯
 ●           (a,c)
(a,c)        
 power γ>1    smoothstep
```

**两端被钉死，中间想怎么弯就怎么弯。** 这就是非线性映射的全部精髓。

一句话总结：**`y = c + f(t) · (d - c)`，换 `f` 就换曲线**。线性是 `f(t)=t`，其它都是把这条直线"捏"成各种形状。
