# `to_n` 的数学推导过程

我们要解决的问题是：**把一个 `[0, 1]` 区间内的浮点数 `val`，线性映射到 `[1, n]` 区间内的整数**。

## 一、线性映射的通用公式

任意一条直线（一次函数）可以写成：

$$
y = a \cdot x + b
$$

我们需要找到合适的 **斜率 `a`** 和 **截距 `b`**，使得：

- 当 `x = 0` 时，`y = 1`（最小值）
- 当 `x = 1` 时，`y = n`（最大值）

### 求截距 `b`

代入 `x = 0, y = 1`：

$$
1 = a \cdot 0 + b \;\Rightarrow\; b = 1
$$

### 求斜率 `a`

代入 `x = 1, y = n`，并把 `b = 1` 带进去：

$$
n = a \cdot 1 + 1 \;\Rightarrow\; a = n - 1
$$

### 得到线性映射公式

$$
\boxed{\,y = (n - 1) \cdot x + 1\,}
$$

## 二、验证一下

| `val` | 计算           | 结果 |
|-------|---------------|-----|
| 0.0   | `(n-1)*0 + 1` | 1   |
| 0.5   | `(n-1)*0.5+1` | (n+1)/2，即中点 |
| 1.0   | `(n-1)*1 + 1` | n   |

完美覆盖 `[1, n]`。

### 回看 `to_5`

当 `n = 5` 时：

$$
y = (5-1) \cdot x + 1 = 4x + 1
$$

这就是代码里 `val * 4 + 1` 的来历 ✅

## 三、为什么还要 `round` 和 `clamp`？

线性公式只能保证**值的范围**对，但不能保证：

1. **结果是整数** —— 所以加 `round(...)` 取整
2. **输入超界时仍安全** —— 所以加 `max(1, min(n, ...))` 钳制

完整公式可以写成：

$$
\text{to\_n}(x) = \mathrm{clamp}\Big(\,\mathrm{round}\big((n-1)\cdot x + 1\big),\; 1,\; n\,\Big)
$$

## 四、通用版 Python 实现

```python
def to_n(val: float, n: int = 5) -> int:
    return max(1, min(n, round(val * (n - 1) + 1)))
```

用法举例：

```python
to_n(0.5, 5)    # → 3   （五星评分，中位）
to_n(0.5, 10)   # → 6   （十分制，因为 round(5.5) = 6 银行家舍入注意）
to_n(0.75, 4)   # → 3   （四级评分）
to_n(1.0, 100)  # → 100 （百分制满分）
```

## 五、扩展：更通用的区间映射

如果输入区间不是 `[0, 1]`，而是任意 `[a, b]`，要映射到 `[c, d]`，公式是：

$$
y = c + (x - a) \cdot \frac{d - c}{b - a}
$$

这就是图形学、归一化处理中最常见的「区间重映射」公式。`to_n` 是它在 `a=0, b=1, c=1, d=n` 时的一个特例。

一句话总结：**两点确定一条直线**——给定 `(0,1)` 和 `(1,n)` 两个端点，斜率截距就唯一确定了，这就是 `val * (n-1) + 1` 的全部来历。
